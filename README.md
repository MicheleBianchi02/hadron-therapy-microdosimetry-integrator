# Current Integrator for Microdosimetry in Clinical Hadron Therapy

This repository contains the design, firmware, and validation of a custom
microcontroller-based Data Acquisition (DAQ) system for microdosimetry
applications in clinical hadron therapy.

This project was developed for the university course *Digital Systems Design*
in the **MSc in Nuclear Engineering** program at **Politecnico di Milano** and
is integrated into the **AToMiQA** project of the **INFN (Istituto Nazionale di
Fisica Nucleare)**. The final objective of the course is to design a
microcontroller-based system and write a research paper.

## Project Overview

The AToMiQA project aims to develop a combined system capable of measuring
microdosimetric quantities, such as the dose-mean lineal energy ($\bar{y}_D$),
at clinical rates, where conventional Pulse-Height Analysis (PHA) fails due to
pile-up effects. The theoretical framework, developed by Kellerer and Rossi
(1984), employs multi-event measurements to retrieve $\bar{y}_D$ from the
variance of the total charge accumulated during a fixed integration window.
This technique is called the variance-covariance method; additional information
can be found in the [paper](./paper.pdf) and [here](./results.pdf).

During the first year of the AToMiQA project, a front-end gated integrator board
was developed to implement the variance-covariance method under proton irradiation.
It consists of a simple electronic integrator with a feedback capacitor and a
switch used to reset the charge accumulated on the capacitor during the integration
phase and bring the output voltage to zero.

The work presented in this repository consists of: the development of the
microcontroller firmware used to control the circuit board and digitize the
output voltage; a control application acting as both a driver for the
microcontroller and online data-processing software; and the validation of the
entire system using a second microcontroller.

## Main Microcontroller

The microcontroller used for this work is the Microchip PIC18F8723, programmed in
assembly. Since the variance-covariance method is based on integrating the
current generated by the detector for a fixed amount of time, timing control
must be highly precise to minimize errors. Therefore, firmware with an
interrupt-driven architecture was developed using the high-precision watch crystal
on the board. The microcontroller handles digitization using its integrated 12-bit
ADC, implementing the correlated double sampling technique ([paper](./paper.pdf)).
The maximum jitter in the digitization timing was measured to be below $200\mathrm{ns}$,
while the firmware allows for integration times from $30 \mu s$ up to $512  s$.
A review of the firmware, including a more in-depth explanation of its architecture,
is provided in the [code review](./docs/firmware_report.pdf).

## Validation System

The measurement system was validated using a second microcontroller (ESP32).
This microcontroller acts as a nuclear emulator, producing voltage pulses with
random durations following a specified Gaussian distribution. In this way, the
charge injected into the gated integrator (through a resistor) is proportional
to the pulse duration. Therefore, when the integrator sums multiple simulated
events, the measured variance depends on the Gaussian distribution used to
generate each event. The theoretical principles are detailed in the
[paper](./paper.pdf) and in the [result summary](./results.pdf).

A review of the ESP32 firmware is provided in the documentation
[here](./docs/generator/ESP32_stochastic_Sim.pdf).

A statistical analysis of the generated distribution was carried out to define
the minimum working parameters of the generator, using a custom Python
simulator. The complete review is presented
[here](./docs/generator/simulations/README.md).

## Use of AI

This work was carried out at the end of 2025, when the AI tools available to
us were not as advanced as they are today. Therefore, all the code in this
repository was handwritten, and no AI tools were used in this project.
